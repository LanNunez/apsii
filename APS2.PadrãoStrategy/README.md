# APS2 - Strategy

Projeto feito para a atividade de Análise e Projeto de Sistemas II.

O programa demonstra o padrão Strategy usando personagens e diferentes tipos de armas.

Os personagens podem trocar de arma durante a execução do programa por meio do método setWeapon().

## Como executar

Abra a classe Main no Eclipse e execute como Java Application.

## Classes principais

- Character
- King
- Queen
- Knight
- Troll
- WeaponBehavior
- Classes de armas
